Configurazione iniziale (una sola volta, ~2 min):
  1. Vai su console.firebase.google.com e crea un progetto (gratis).
  2. Menu Build → Firestore Database → Crea database → modalità test.
  3. In ⚙️ Impostazioni progetto → Le tue app, aggiungi un'app Web </> e copia l'oggetto firebaseConfig.
  4. Incollalo qui sotto 👇

Potrai aggiungere altri membri in seguito. La configurazione resta sul tuo telefono.
